Implement POSIX-style backslash-newline line continuation so real shell scripts like `benches/shellbench.sh` can parse under Rush.

Context:
- `./target/release/rush --no-rc benches/shellbench.sh` currently fails on a long argument list split with `\` newline continuation.
- This is a high-leverage compatibility gap because line continuation is common in real shell scripts and benchmark fixtures.

Goal:
- Make a trailing backslash before newline continue the logical line during lex/parse as users expect.
- Keep scope to this compatibility behavior; do not broaden into unrelated quoting features.
