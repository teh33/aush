After fixing exec builtin errors, full `cargo test` progressed to `tests/function_calling_test.rs` failures.

Failing tests:
- `test_local_error_outside_function`: expects `local` outside a function to return `Err`.
- `test_shift_error_when_no_params`: expects invalid shift with no params to return `Err`.
- `test_shift_error_when_count_exceeds_params`: expects shift count exceeding function params to return `Err`.

Likely same executor wrapper issue: builtins `local` and `shift` probably return `Err`, but executor converts most builtin errors into successful `ExecutionResult::error`. Inspect `src/builtins/local.rs` or equivalent and `src/builtins/shift.rs`, then decide whether these builtins should propagate `Err` like `command`/`exec` or whether builtin implementations need changes.

Scope:
- Fix only `local`/`shift` error reporting semantics needed by function tests.
- Preserve valid function/local/shift behavior.
- Avoid changing unrelated builtin semantics.
