Run the final local release gate for an AUSH alpha release after the full no-legacy rebrand.

Prerequisites:
- Full rebrand unit 24.7 complete: package/lib/binary/daemon/docs use AUSH/AUSHD only, no legacy Rush binary or rushd.
- Release testing docs 24.5 complete.

Steps:
1. Ensure the rebrand diff is reviewed enough to trust; do not publish from an unreviewed dirty worktree.
2. Run `cargo test` and record any failures exactly; do not hide failures with `|| true`.
3. Run `cargo build --release --bins`.
4. Run `tests/smoke_test.sh ./target/release/aush`.
5. Create a temporary local archive from `target/release/aush` and `target/release/aushd`; extract it into a temp dir; verify `aush --no-rc -c 'echo ok'` and `aushd --help` or equivalent daemon-safe command.
6. Run `cargo package --list` and scan for obviously unwanted large/generated/private files. If package contents are bad, create a follow-up or fix with include/exclude before release.
7. Confirm `cargo publish --dry-run --allow-dirty` packages/verifies `aush`.

Out of scope: actual crates.io publish, git tag creation, GitHub release, Homebrew checksum update, pushing commits, or force operations. Those require explicit approval.
