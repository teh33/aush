Run the final local release gate for an AUSH alpha release after package identity and release docs are cleaned.

Prerequisites:
- 24.4 complete: `cargo publish --dry-run` verifies package `aush`.
- 24.5 complete: release testing docs reference AUSH artifacts.

Steps:
1. Run `cargo test` and record any failures exactly; do not hide failures with `|| true`.
2. Run `cargo build --release --bins`.
3. Run `tests/smoke_test.sh ./target/release/aush`.
4. Create a temporary local archive from `target/release/aush` and `target/release/rush`; extract it into a temp dir; verify both executables run `--no-rc -c 'echo ok'`.
5. Run `cargo package --list` and scan for obviously unwanted large/generated/private files. If package contents are bad, create a follow-up or fix with include/exclude before release.

Out of scope: actual crates.io publish, git tag creation, GitHub release, Homebrew checksum update, or pushing commits. Those require explicit approval.
